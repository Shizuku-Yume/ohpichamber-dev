# Встановлення

OpenChamber можна запускати як:

- десктопний застосунок для macOS, Windows і Linux
- вебзастосунок на базі CLI, який також можна встановити як PWA
- мобільний застосунок для iOS та Android

## Веб + PWA

Для роботи сервера OpenChamber необхідно задовольнити попередні вимоги: Node.js 24.14+ для Host Gateway, Bun 1.3.14+ у PATH для Agent Service та git.

```bash
curl -fsSL https://raw.githubusercontent.com/openchamber/openchamber/main/scripts/install.sh | bash
openchamber --ui-password be-creative-here
```

Відкрийте URL, який вивів CLI (зазвичай `http://localhost:3000`). Введіть свій пароль UI на екрані входу, щоб увійти. Після входу ви побачите список сесій OpenChamber. Щоб він був під рукою, скористайтеся опцією «Install» в адресному рядку браузера й додайте його як застосунок.

## Десктоп

Завантажте найновішу десктопну збірку для вашої платформи зі сторінки релізів на GitHub або зі сторінки завантаження OpenChamber. Запустіть застосунок і виберіть свій робочий простір або підключіться до віддаленого сервера.
