# Оновлення

Те, як ви оновлюєте OhPiChamber, залежить від того, як ви його встановили. У будь-якому разі ви можете перевірити свою поточну версію в **Settings → OhPiChamber → About**.

## Десктопний застосунок

Десктопний застосунок перевіряє наявність оновлень у релізах GitHub. Коли воно доступне, OhPiChamber повідомляє вам, завантажує його, коли ви оберете, і встановлює при наступному перезапуску. Ви завжди керуєте процесом — нічого не встановлюється без вашого схвалення.
