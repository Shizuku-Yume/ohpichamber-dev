# Швидкий старт

## Найшвидший шлях

1. Встановіть OpenChamber та переконайтеся, що виконано попередні вимоги (Node.js 24.14+ та Bun 1.3.14+ у PATH, див. [Встановлення](/uk/install/)).
2. Виконайте `openchamber --ui-password be-creative-here`.
3. Відкрийте URL, який вивів CLI (зазвичай `http://localhost:3000`) та увійдіть за допомогою пароля UI.
4. Щоб користуватися з телефона, запустіть [тунель](/uk/tunnels/) і відскануйте QR-код.

У браузері ви маєте побачити список сесій OpenChamber. Якщо він завантажився — все працює.

Використовуйте надійний пароль UI, особливо якщо плануєте відкривати доступ до інстансу з інтернету.

Якщо сторінка не завантажується, перегляньте [Усунення несправностей](/uk/troubleshooting/).

## Яку платформу обрати?

- обирайте **десктоп** для щоденної роботи на macOS, Windows або Linux
- обирайте **веб** для віддаленого доступу та перегляду з телефона
