# プロバイダー、モデル、エージェント

OpenChamber が何かを行うには、少なくとも 1 つの AI プロバイダーが接続されている必要があります。このページでは、プロバイダーの接続、モデルの選択、エージェントの調整について説明します。

## プロバイダーを接続する

1. **Settings → Providers** を開きます。
2. **Add provider** メニューを開き、まだ接続されていないプロバイダーを選びます。
3. プロバイダーに応じて、次のどちらかの方法でサインインします。
   - **API key** — キーを貼り付けて保存します。
   - **OAuth サインイン** — ブラウザーで認証リンクを開いてサインインします。案内が表示された場合は認証コードを OpenChamber に貼り付け、接続を完了します。

### カスタムおよびその他のプロバイダー

ゲートウェイ、ローカル LLM、Ollama、LiteLLM、および同様の OpenAI 互換 API 向け:

1. プロバイダー一覧で **Other / Custom** を選びます。
2. プロバイダー ID、表示名、ベース URL (`http://` または `https://`)、任意の API キー、および少なくとも 1 つのモデル ID と名前を入力します。
3. モデルのコンテキストウィンドウと最大出力トークン数を指定します。推論オプション、バリアント、モダリティなどの詳細メタデータは、モデル詳細の JSON で設定できます。
4. 必要に応じてリクエストヘッダーを追加します。
5. 保存します — OpenChamber は Agent Service 経由でプロバイダーとモデルを登録し、API キーを書き込み専用の認証情報として保存します。
6. 既存のカスタムプロバイダーを変更するには、該当プロバイダーを開いて **Edit** を選びます。

API キーは任意です。キー不要のローカルエンドポイント（Ollama、LiteLLM、llama.cpp など）やカスタムヘッダー認証を使用するサービスは、API キーなしで接続できます。

プロバイダーが接続済みとして表示されると、そのモデルがチャットで使えるようになります。

切断するには、プロバイダーを開き、サインインを削除する操作を選びます。

## モデルを選ぶ

作業している場所でモデルを選びます。

- チャットでは、メッセージバーのモデルピッカーを使って、そのセッションのプロバイダーとモデルを設定します
- エージェントごとに、デフォルトモデルを設定します（下記）

## エージェントを設定する

エージェントは、名前付きの設定です。モデル、人格、許可された操作をまとめます。

1. **Settings → Agents** を開きます。
2. エージェントを選ぶか、新しく作成します。
3. 次の項目を編集できます。
   - **description** — エージェントの用途
   - **model** — デフォルトモデル
   - **temperature** — 回答の創造性
   - **prompt** — 常に従う固定指示
   - **tool rules** — 使用してよいツール

## サインイン情報の保存場所

プロバイダーの認証情報とサインイン情報はサーバー上の Agent Service 認証情報ストアに保存され、キーは安全に分離保持されます。1 つのプロバイダーに対して複数のアカウントを接続し、プロバイダーのアカウント一覧からデフォルトとして使用するアクティブなアカウントを選択できます。
