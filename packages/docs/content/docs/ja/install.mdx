# インストール

作業スタイルに合ったアプリを選んでください。

- macOS、Windows、Linux 向けのデスクトップアプリ
- CLI がホストする Web アプリ（PWA としてもインストール可能）
- iOS および Android 向けのモバイルアプリ

## Web + PWA

OpenChamber サーバーの実行には前提条件を満たす必要があります：Host Gateway 用の Node.js 24.14+、Agent Service 用の PATH 内の Bun 1.3.14+、および git。

```bash
curl -fsSL https://raw.githubusercontent.com/openchamber/openchamber/main/scripts/install.sh | bash
openchamber --ui-password be-creative-here
```

CLI が表示する URL（通常は `http://localhost:3000`）を開きます。ログイン画面で UI パスワードを入力してログインします。ログインすると OpenChamber のセッション一覧が表示されます。すぐ使えるようにしておくには、ブラウザのアドレスバーにある「インストール」オプションでアプリとして追加します。
