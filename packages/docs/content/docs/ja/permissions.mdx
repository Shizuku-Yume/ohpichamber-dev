# 権限とセーフティネット

エージェントの操作（コマンドの実行、ファイルの編集、MCP ツールの呼び出し、ページの取得）は、すべて Host オーソライザーと Agent Service のワーカーポリシーによって評価されます。OpenChamber の権限モードは、操作に承認が必要な場合の動作を決定します。

## 認可と承認

Host Gateway はプロジェクトディレクトリを基準にファイルシステムアクセスを検証します。プロジェクトルート外のパスを対象とする操作は直ちに拒否されます。プロジェクトルート内では、通常のファイル読み取りや編集はプロジェクトのファイルツールを通じて追加の確認なしに進みます。

未認可のシェルコマンド実行など、ユーザーの同意が必要な操作が発生した場合、エージェントは一時停止して承認要求を作成します。承認要求に応答する際、1 回のみ許可する、セッション全体で常に許可する、またはワークスペース全体で拒否することができます。永続化された承認ポリシーには、セッション単位の許可またはワークスペース単位の拒否が保存されます。

エージェントが表示・呼び出しできるツールを設定するには、**設定 → エージェント** の **許可されたツール**（allowed tools）フィールドを使用します。新しいセッションの既定の権限モードを選ぶには、**設定 → セッション** を使用します。

## 3 つのモード

| モード | 承認要求に応答するのは |
| --- | --- |
| **毎回確認** | あなたです。すべての要求があなたの返答を待ちます。 |
| **セーフティネット** | Jev が日常的な操作を通し、危険な操作はあなたに残します。 |
| **すべて承認** | OpenChamber。同意が必要な要求を自動で承認します。 |

**すべて承認** モードでは、同意が必要な要求は自動的に承認され、確認を待たずに作業が続行されます。ワークスペースディレクトリ境界やワークスペース拒否ポリシーを含む Host のセキュリティ境界チェックは、すべての操作で常に実行されます。

## モードを切り替える

- **1 つのセッションだけ：** 入力欄の盾のボタンを押します。押すたびに次のモードに切り替わります。
- **新しいセッション：** **設定 → セッション → 権限** で既定のモードを選びます。既存のセッションはそのままです。

サブエージェントは、自分を起動したセッションのモードに従います。

## セーフティネット

このモードでは、OpenChamber が要求ごとに [Jev](/ja/classification-providers/) に尋ねます。これは日常的な操作か、それともあなたが判断すべきか。読み取り、ビルド、テストの実行、プロジェクトファイルの編集、普通のコミットは通ります。git 履歴の書き換え、データの削除、システムの変更、デプロイ、どこかへの投稿、外部へのファイル送信は、はっきりしないものと同じく、あなたの判断を待ちます。

保留された要求は、ツール名、コマンドの概要、詳細を含む承認カードとしてチャットに表示され、許可または拒否を選択できます。Jev が 4 秒以内に答えない場合も、操作はあなたを待ちます。分類が失敗またはタイムアウトしたときに、セーフティネットが操作を許可することはありません。

セーフティネットには[分類プロバイダー](/ja/classification-providers/)が必要です。ない場合、盾のボタンはこのモードを飛ばし、設定でも無効になります。

## 離れていても動き続ける

モードは OpenChamber サーバーにあるので、タブを閉じたりスマートフォンをロックしたりしても要求に答え続け、再起動後も保たれます。

- [通知](/ja/notifications/)：要求があなたを待っているときに知らせを受ける
