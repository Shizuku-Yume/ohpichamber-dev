# クイックスタート

## 最短手順

1. OpenChamber をインストールし、動作要件（Node.js 24.14+ および PATH 内の Bun 1.3.14+）を満たしていることを確認します（[インストール](/install/) を参照）。
2. `openchamber --ui-password be-creative-here` を実行します。
3. CLI が表示する URL（通常は `http://localhost:3000`）を開き、UI パスワードでログインします。
4. スマートフォンから使うには、[トンネル](/tunnels/) を開始して QR コードをスキャンします。

ログイン後、ブラウザに OpenChamber のセッション一覧が表示されます。読み込まれれば、起動できています。

特にインスタンスをインターネットに公開する予定がある場合は、強力な UI パスワードを使ってください。

ページが読み込まれない場合は、[トラブルシューティング](/troubleshooting/) を確認してください。

## どのアプリを使うべきですか？

- macOS、Windows、Linux での日常作業には **desktop** を使います
- リモートアクセスやスマートフォンからの確認には **web** を使います
