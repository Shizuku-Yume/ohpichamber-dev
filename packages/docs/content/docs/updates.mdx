# Updates

How you update OhPiChamber depends on how you installed it. In every case you can check your current version at **Settings → OhPiChamber → About**.

## Desktop app

The desktop app checks for updates against GitHub releases. When one is available, OhPiChamber tells you, downloads it when you choose, and installs it on the next restart. You're always in control — nothing installs without your say-so.
