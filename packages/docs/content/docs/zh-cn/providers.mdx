# 提供商、模型与智能体

在 OpenChamber 能做任何事之前，它至少需要连接一个 AI 提供商。本页介绍如何连接提供商、选择模型以及定制智能体。

## 连接提供商

1. 打开 **Settings → Providers**。
2. 打开 **Add provider** 菜单，选择一个尚未连接的提供商，或为兼容 OpenAI 的端点选择 **Other / Custom**。
3. 根据提供商要求的方式登录：
   - **API 密钥** — 粘贴你的密钥并保存。
   - **OAuth 登录** — 在浏览器中打开授权链接以登录。若有提示，将授权码粘贴回 OpenChamber，然后完成连接。

### 自定义与其它提供商

适用于网关、本地模型、Ollama、LiteLLM 以及类似兼容 OpenAI 的 API：

1. 在提供商列表中选择 **Other / Custom**。
2. 输入提供商 ID、显示名称、基础 URL（`http://` 或 `https://`）、可选的 API 密钥以及至少一个模型 ID 和名称。
3. 输入模型的上下文窗口与最大输出令牌数。高级元数据（例如推理选项、变体和模态）可在模型详情下配置为 JSON。
4. 可选添加请求头。
5. 保存 — OpenChamber 通过 Agent Service 注册提供商和模型，并将 API 密钥作为只写凭据存储。
6. 若要修改现有的自定义提供商，打开该提供商并选择 **Edit**。

API 密钥为选填项。无需密钥的本地端点（如 Ollama、LiteLLM 或 llama.cpp）以及使用自定义请求头认证的服务无需 API 密钥即可连接。

当提供商显示为已连接时，它的模型就会在聊天中可用。

要断开连接，请打开该提供商并选择移除其登录。

## 选择模型

你在工作的地方选择模型：

- 在聊天中，使用消息栏中的模型选择器为该会话设置提供商和模型
- 按智能体设置默认模型（见下文）

## 设置智能体

智能体是一个命名的配置 — 包括一个模型、系统提示词，以及它可以调用的工具。

1. 打开 **Settings → Agents**。
2. 选择一个智能体，或创建一个新的。
3. 编辑以下任意项：
   - **description** — 该智能体的用途
   - **model** — 覆盖该智能体的默认提供商与模型
   - **prompt** — 它始终遵循的系统提示词与固定指令
   - **allowed tools** — 该智能体可用的工具列表（定义工具可用性；操作执行授权仍由主机策略与审批控制）
   - **permission preset** — 可选的权限预设 ID

## 你的登录信息存储在哪里

提供商凭据与登录信息存储在服务器上的 Agent Service 凭据存储中，确保密钥安全且相互隔离。你可以为一个提供商连接多个账户，并在提供商的账户列表中选择作为默认使用的活动账户。
