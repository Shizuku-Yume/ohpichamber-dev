# 安装

选择适合你工作方式的应用：

- 面向 macOS、Windows 和 Linux 的桌面应用
- 由 CLI 托管的 Web 应用，也可作为 PWA 安装
- 面向 iOS 和 Android 的移动应用

## Web + PWA

运行 OpenChamber 服务端需要满足前置依赖：Node.js 24.14+（主机网关）、PATH 中的 Bun 1.3.14+（Agent Service）以及 git。

```bash
curl -fsSL https://raw.githubusercontent.com/openchamber/openchamber/main/scripts/install.sh | bash
openchamber --ui-password be-creative-here
```

打开 CLI 输出的 URL（通常是 `http://localhost:3000`）。在登录界面输入你的 UI 密码完成登录。登录后即可看到 OpenChamber 会话列表。想随手取用，可以使用浏览器地址栏中的“安装”选项，把它添加为一个应用。
