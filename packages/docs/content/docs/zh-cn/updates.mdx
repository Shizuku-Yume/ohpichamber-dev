# 更新

你如何更新 OhPiChamber 取决于你如何安装它。在任何情况下，你都可以在 **Settings → OhPiChamber → About** 查看你的当前版本。

## 桌面应用

桌面应用会对照 GitHub 发布版本检查更新。当有可用更新时，OhPiChamber 会告诉你，在你选择时下载它，并在下次重启时安装它。一切都由你掌控 — 没有你的同意不会安装任何东西。
