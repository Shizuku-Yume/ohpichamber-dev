# 权限与安全网

智能体的每个操作（运行命令、编辑文件、调用 MCP 工具、抓取网页）都会由主机授权器和 Agent Service 工作进程策略进行评估。OpenChamber 的权限模式决定操作需要确认时的处理方式。

## 授权与审批

主机网关对文件系统的访问受项目目录边界约束。任何访问项目根目录外部路径的操作都会直接被拒绝。在项目根目录内部，常规的文件读取和编辑通过项目文件工具执行，无需额外确认。

当操作需要用户同意时（例如运行未经授权的 Shell 命令），智能体会暂停并生成审批请求。处理审批请求时，你可以单次允许、在当前会话中始终允许，或在工作区范围内拒绝。持久化的审批策略存储会话范围的允许或工作区范围的拒绝。

若要配置智能体可见并可调用的工具，请在 **设置 → 智能体** 中配置 **允许的工具**（allowed tools）。若要为新会话选择默认权限模式，请使用 **设置 → 会话**。

## 三种模式

| 模式 | 谁来处理审批请求 |
| --- | --- |
| **每次询问** | 你。每个请求都等你答复。 |
| **安全网** | Jev 放行日常操作，把有风险的留给你。 |
| **全部接受** | OpenChamber。自动批准需要确认的请求。 |

在 **全部接受** 模式下，需要用户同意的请求会自动批准，无需等待交互。主机的安全边界检查（包括工作区目录约束和工作区拒绝策略）仍对每个操作无条件执行。

## 切换模式

- **单个会话：** 点输入框里的盾牌按钮。每点一次切换到下一个模式。
- **新会话：** 在 **设置 → 会话 → 权限** 中选择默认模式。已有会话保持各自的模式。

子智能体跟随启动它们的会话。

## 安全网

在这个模式下，OpenChamber 会就每个请求询问 [Jev](/zh-cn/classification-providers/)：这是日常操作，还是应该由你决定？读取、构建、运行测试、编辑项目文件和普通提交都会放行。改写 git 历史、删除数据、修改系统、部署、在某处发布内容或把文件发送到外部，都会等你决定，所有不明确的操作也一样。

被暂停的请求会在聊天中显示审批卡片，包含工具名称、命令摘要和详细信息，供你选择允许或拒绝。如果 Jev 四秒内没有回应，操作同样会等你。分类失败或超时时，安全网绝不会放行任何操作。

安全网需要[分类提供方](/zh-cn/classification-providers/)。没有时，盾牌按钮会跳过这个模式，设置里它也会被禁用。

## 你不在时也照常工作

模式保存在 OpenChamber 服务器上，所以即使你关掉标签页或锁上手机，它也会继续回应请求，重启后也会保留。
