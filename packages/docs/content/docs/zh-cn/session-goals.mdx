# 会话目标


目标使用 Agent Service worker 中的 OMP Goal 模式。OMP 发起后续轮次，由代理声明完成。OpenChamber 不会运行单独的 supervisor 或独立审核模型。

## 启动目标

1. 按下输入框中的靶心按钮。它亮起 — 目标模式已就绪。
2. 输入提示词并发送。这条消息就成为目标内容。

在现有会话和新会话草稿中都一样：启用靶心，写下第一条消息，发送 — 新会话一开始就带着已激活的目标。

### 启动目标的更多方式

- **从代理回复开始**：在对话框中勾选**作为目标运行**，即可将回复作为 OMP 目标执行。
- **从计划开始**：在新会话或 worktree 中实施已保存的计划时，勾选**作为目标运行**。计划内容会成为 OMP 目标。
- **按计划**：在[计划任务](/scheduled-tasks/)上勾选**作为目标运行**，让周期性运行把提示词推进到完成。

## 写一个自包含的目标

请写出清晰、可验证的最终结果，让代理不依赖隐藏的聊天上下文也能理解。

- 好的写法："为导出模块添加测试，并让整个测试套件通过。"
- 不太好的写法："修一下" 或 "按那个思路继续。"

对于小的上下文跟进，不需要目标 — 发一条普通消息就行。

## 工作原理

OMP 在同一会话中发起每个后续轮次。代理通过 Goal 工具声明完成；达到令牌预算、后续轮次不再取得进展，或你暂停、删除目标或中止当前轮次时，OMP 也会停止。

### 停止与恢复

- **停止按钮**会中断正在运行的轮次并暂停目标 — 你明确的"停"永远优先于循环。
- 条带上的**暂停**从另一个方向做同样的事：暂停目标并停止正在运行的轮次。
- 暂停期间正常聊天即可 — 循环不会打扰。
- **继续**重新启动循环：在空闲会话上，续跑提示词会立即发出；如果代理恰好在工作，循环会在它下一次停顿时静静接上。

## 查看与管理

- 输入框上方的条带显示目标、状态和令牌用量，并提供暂停和继续操作。
- 靶心按钮和会话侧边栏图标反映 OMP Goal 状态。你可以在对话框中更改目标或预算，也可以移除目标。
- 在会话侧边栏中，会话日期旁会出现一个小靶心，颜色对应目标状态。

## 通知

OMP 目标激活期间，每轮之后不会发送“代理就绪”通知。目标完成或达到预算时会发送通知。权限请求、提问和错误通知仍照常工作。

## 令牌预算

在 **设置 → 聊天 → 目标** 中可以为新目标设置默认令牌预算。目标达到预算时会以"已达预算"停止而不再消耗 — 你可以提高预算并从目标对话框中恢复。

## 注意事项

- 目标运行在 Agent Service 的 OMP 会话 worker 中，而不是单独的 Host 循环中。服务器需要保持运行。
- OMP 使用会话自身的提供商和模型，不会调用独立审核模型。
- 每个会话同时只能有一个目标。
