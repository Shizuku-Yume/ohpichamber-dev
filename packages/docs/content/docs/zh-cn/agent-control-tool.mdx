# 智能体控制工具

使用 `openchamber` 智能体工具直接从聊天中管理应用内的工作。此工具默认启用；无需安装单独的工具或运行 shell 命令。

## 可以提出的请求

用平常的话告诉智能体即可。例如：

- “在这个项目中新建一个 OhPiChamber 会话，使用 `openai/gpt-5.6-sol` 模型，并发送这条提示：审查认证流程。”
- “为这个任务在单独的 worktree 中新建一个 OhPiChamber 会话，让它为登录流程添加测试。”
- “用 OhPiChamber 列出我最近的 10 个会话及其当前状态。”
- “创建一个名为工作日审查的 OhPiChamber 计划任务，每个工作日 09:00 发送这条提示：审查自上次运行以来的改动。”
- “立即运行名为工作日审查的 OhPiChamber 计划任务。”
- “查看名为认证审查的 OhPiChamber 会话，并给我看助手的最新回复。”

控制工具可以列出项目和模型偏好，搜索模型目录，创建并跟进会话，派生会话，以及创建隔离的 worktree 会话。计划工具可以创建、修改、运行、暂停和删除计划任务。这样启动的会话会像其他会话一样出现在 OhPiChamber 中，你可以打开它们并亲自继续工作。

## 注意事项

- 发给新会话的提示默认会立即返回。在 OhPiChamber 中跟进会话，或让智能体稍后再查看。
- 只有在你要求时才会创建单独的 worktree。当前 worktree 中未提交的改动不会复制过去。
- 当检出看起来正被占用时，例如另一个会话在同一分支上工作，智能体可能会提议把自己的会话移到新的 worktree。它在你同意后才移动，并且只带走自己改动过的文件。
- 这些工具不能删除会话或 worktree，不能注册项目路径，不能运行任意 shell 命令，也不能调用任意 URL。

## 开启或关闭工具

打开 **设置 → 常规 → OhPiChamber 工具**，更改 **智能体控制工具**。该设置即时生效，无需重启。该工具通过 OhPiChamber 原生主机操作边界运行，用以管理会话、worktree 和计划任务。
