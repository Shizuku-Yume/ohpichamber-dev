# 세션 목표


목표는 Agent Service worker에서 OMP Goal 모드로 실행됩니다. OMP가 후속 턴을 시작하고 에이전트가 완료를 선언합니다. OpenChamber는 별도의 supervisor나 독립 감사 모델을 실행하지 않습니다.

## 목표 시작하기

1. 컴포저의 타깃 버튼을 누릅니다. 불이 켜지면 목표 모드가 준비된 것입니다.
2. 프롬프트를 작성하고 전송합니다. 그 메시지가 목표가 됩니다.

기존 세션과 새 세션 초안 모두에서 동일하게 작동합니다. 타깃을 켜고 첫 메시지를 작성해 전송하면 — 새 세션이 목표가 이미 활성화된 상태로 시작됩니다.

### 목표를 시작하는 다른 방법

- **에이전트 답변에서**: 답변을 OMP 목표로 실행하려면 대화 상자에서 **목표로 실행**을 선택하세요.
- **계획에서**: 새 세션이나 worktree에서 저장된 계획을 구현할 때 **목표로 실행**을 선택하세요. 계획 내용이 OMP 목표가 됩니다.
- **일정에 따라**: [예약 작업](/scheduled-tasks/)에서 **목표로 실행**을 체크하면 반복 실행이 프롬프트를 완료까지 추진합니다.

## 자기 완결적인 목표 작성하기

채팅의 숨겨진 맥락 없이도 에이전트가 이해할 수 있도록 명확하고 검증 가능한 완료 상태를 작성하세요.

- 좋은 예: "내보내기 모듈에 테스트를 추가하고 전체 테스트 스위트를 통과시켜."
- 좋지 않은 예: "고쳐줘" 또는 "그 아이디어로 계속해."

작은 맥락적 후속 지시에는 목표가 필요 없습니다 — 그냥 일반 메시지를 보내세요.

## 작동 방식

OMP는 같은 세션 안에서 후속 턴을 시작합니다. 에이전트는 Goal 도구로 완료를 선언합니다. 토큰 예산에 도달하거나, 후속 턴에서 진행되지 않거나, 목표를 일시 중지·삭제하거나 실행 중인 턴을 중단해도 OMP는 멈춥니다.

### 중지와 재개

- **중지 버튼**은 실행 중인 턴을 중단하고 목표를 일시 중지합니다 — 당신의 명시적인 "멈춰"가 항상 루프보다 우선합니다.
- 스트립의 **일시 중지**는 반대 방향에서 같은 일을 합니다: 목표를 일시 중지하고 실행 중인 턴을 멈춥니다.
- 일시 중지 중에는 평소처럼 채팅하세요 — 루프가 끼어들지 않습니다.
- **재개**는 루프를 다시 켭니다: 유휴 세션에서는 계속 프롬프트가 즉시 나가고, 에이전트가 작업 중이라면 다음 멈춤에서 루프가 조용히 다시 붙습니다.

## 확인 및 관리

- 컴포저 위의 스트립에 목표, 상태, 토큰 사용량이 표시되고 일시 중지 및 재개를 제어할 수 있습니다.
- 타깃 버튼과 사이드바 아이콘은 OMP Goal 상태를 보여줍니다. 대화 상자에서 목표나 예산을 바꾸거나 목표를 삭제할 수 있습니다.
- 세션 사이드바에서 세션 날짜 옆에 목표 상태 색상의 작은 타깃이 나타납니다.

## 알림

OMP 목표가 활성 상태인 동안에는 매 턴 뒤에 "에이전트 준비 완료" 알림을 보내지 않습니다. 목표 완료 또는 예산 도달 시 알림이 옵니다. 권한 요청, 질문, 오류 알림은 평소처럼 작동합니다.

## 토큰 예산

**설정 → 채팅 → 목표**에서 새 목표의 기본 토큰 예산을 설정할 수 있습니다. 목표가 예산에 도달하면 더 소비하지 않고 "예산 도달"로 멈춥니다 — 예산을 올리고 목표 대화 상자에서 재개할 수 있습니다.

## 유의 사항

- 목표는 Host의 별도 루프가 아니라 Agent Service의 OMP 세션 worker에서 실행됩니다. 서버를 계속 실행해야 합니다.
- OMP는 세션의 제공자와 모델을 사용하며 독립 감사 모델을 호출하지 않습니다.
- 세션당 목표는 한 번에 하나입니다.

## 관련

- [예약 작업](/scheduled-tasks/) — 일정에 따라 프롬프트 실행; "목표로 실행"을 켜면 예약 실행이 프롬프트를 완료까지 추진합니다
- [알림](/notifications/) — 완료된 목표를 알게 되는 방법
