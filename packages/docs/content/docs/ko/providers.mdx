# 공급자, 모델, 에이전트

OpenChamber가 무언가를 하려면 먼저 최소한 하나의 AI 공급자가 연결되어 있어야 합니다. 이 페이지에서는 공급자 연결, 모델 선택, 에이전트 맞춤 설정을 다룹니다.

## 공급자 연결하기

1. **Settings → Providers**를 엽니다.
2. **Add provider** 메뉴를 열고 아직 연결되지 않은 공급자를 선택하거나, OpenAI 호환 엔드포인트의 경우 **Other / Custom**을 선택합니다.
3. 공급자가 요구하는 방식에 따라 로그인합니다.
   - **API key** — 키를 붙여넣고 저장합니다.
   - **OAuth 로그인** — 브라우저에서 인증 링크를 열어 로그인합니다. 안내가 표시되면 인증 코드를 OpenChamber에 붙여넣고 연결을 완료합니다.

### 사용자 지정 및 기타 공급자

게이트웨이, 사내 LLM, Ollama, LiteLLM 및 유사한 OpenAI 호환 API:

1. 공급자 목록에서 **Other / Custom**을 선택합니다.
2. 공급자 ID, 표시 이름, 기본 URL(`http://` 또는 `https://`), 선택 사항인 API 키, 그리고 최소 하나의 모델 ID와 이름을 입력합니다.
3. 모델의 컨텍스트 창과 최대 출력 토큰 수를 입력합니다. 추론 옵션, 변형, 모달리티와 같은 고급 메타데이터는 모델 세부정보의 JSON에서 설정할 수 있습니다.
4. 필요한 경우 요청 헤더를 추가합니다.
5. 저장 — OpenChamber는 Agent Service를 통해 공급자와 모델을 등록하며, API 키를 쓰기 전용 자격 증명으로 저장합니다.
6. 기존 사용자 지정 공급자를 수정하려면 해당 공급자를 열고 **Edit**을 선택합니다.

API 키는 선택 사항입니다. 키가 필요 없는 로컬 엔드포인트(Ollama, LiteLLM, llama.cpp 등)나 사용자 지정 헤더 인증을 사용하는 서비스는 API 키 없이 연결할 수 있습니다.

공급자가 연결됨으로 표시되면 해당 모델을 채팅에서 사용할 수 있습니다.

연결을 해제하려면 공급자를 열고 로그인을 제거하도록 선택합니다.

## 모델 선택하기

작업하는 위치에서 모델을 선택합니다.

- 채팅에서는 메시지 바의 모델 선택기로 해당 세션의 공급자와 모델을 설정합니다
- 에이전트별로 기본 모델을 설정합니다(아래 참고)

## 에이전트 설정하기

에이전트는 모델, 시스템 프롬프트, 사용할 수 있는 도구를 묶어 이름을 붙인 설정입니다.

1. **Settings → Agents**를 엽니다.
2. 에이전트를 선택하거나 새로 만듭니다.
3. 다음 항목을 편집합니다.
   - **description** — 에이전트의 용도
   - **model** — 기본 공급자 및 모델 재정의
   - **prompt** — 항상 따르는 시스템 프롬프트 및 상시 지침
   - **allowed tools** — 에이전트가 사용할 수 있는 도구 목록(도구 가용성: 여기에 도구를 지정하면 모델이 호출할 수 있게 되며, 작업 실행 인가는 Host 정책과 승인을 통해 제어됩니다)
   - **permission preset** — 프로필에 대한 선택적 권한 사전 설정 ID

## 로그인 정보가 저장되는 위치

공급자 자격 증명과 로그인 정보는 서버의 Agent Service 자격 증명 저장소에 안전하게 격리되어 보관됩니다. 한 공급자에 여러 계정을 연결할 수 있으며, 공급자의 계정 목록에서 기본으로 사용할 활성 계정을 선택할 수 있습니다.
