# 설치

작업 방식에 맞는 앱을 고르세요.

- macOS, Windows, Linux용 데스크톱 앱
- CLI가 호스팅하며 PWA로도 설치할 수 있는 웹 앱
- iOS 및 Android용 모바일 앱

## 웹 + PWA

OpenChamber 서버를 실행하려면 사전 요구 사항을 충족해야 합니다: Host Gateway용 Node.js 24.14+, Agent Service용 PATH의 Bun 1.3.14+, 그리고 git.

```bash
curl -fsSL https://raw.githubusercontent.com/openchamber/openchamber/main/scripts/install.sh | bash
openchamber --ui-password be-creative-here
```

CLI가 출력한 URL을 여세요(보통 `http://localhost:3000`). 로그인 화면에서 UI 비밀번호를 입력하여 로그인하세요. 로그인하면 OpenChamber 세션 목록이 표시됩니다. 자주 사용하려면 브라우저 주소창의 "설치" 옵션으로 앱처럼 추가하세요.
