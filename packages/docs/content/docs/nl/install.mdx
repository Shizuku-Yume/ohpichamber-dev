# Installeren

Kies de app die past bij hoe u werkt:

- als desktopapp voor macOS, Windows en Linux
- als webapp via de CLI, ook te installeren als PWA
- als mobiele app voor iOS en Android

## Web en PWA

Voor het uitvoeren van OpenChamber gelden de volgende vereisten: Node.js 24.14+ voor de Host Gateway, Bun 1.3.14+ op het PATH voor de Agent Service en git.

```bash
curl -fsSL https://raw.githubusercontent.com/openchamber/openchamber/main/scripts/install.sh | bash
openchamber --ui-password be-creative-here
```

Open de URL die de CLI toont (meestal `http://localhost:3000`). Voer uw UI-wachtwoord in op het inlogscherm om u aan te melden. Zodra u bent aangemeld, ziet u de sessielijst van OpenChamber. Via de optie 'Installeren' in de adresbalk van uw browser kunt u de webapp als app toevoegen.
