# Installieren

Wähle die App, die zu deiner Arbeitsweise passt:

- Desktop-App für macOS, Windows und Linux
- Web-App, die vom CLI gehostet wird und als PWA installiert werden kann
- Mobile-App für iOS und Android

## Web + PWA

Der Betrieb von OpenChamber erfordert erfüllte Voraussetzungen: Node.js 24.14+ für das Host-Gateway, Bun 1.3.14+ im PATH für den Agent Service sowie git.

```bash
curl -fsSL https://raw.githubusercontent.com/openchamber/openchamber/main/scripts/install.sh | bash
openchamber --ui-password be-creative-here
```

Öffne die URL, die das CLI ausgibt (normalerweise `http://localhost:3000`). Gib dein UI-Passwort im Anmeldefenster ein, um dich anzumelden. Nach der Anmeldung siehst du die OpenChamber-Session-Liste. Damit du sie griffbereit hast, kannst du im Adressfeld deines Browsers über die Option „Installieren“ daraus eine App machen.
