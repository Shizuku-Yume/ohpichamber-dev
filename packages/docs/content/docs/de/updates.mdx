# Updates

Wie Sie OhPiChamber aktualisieren, hängt davon ab, wie Sie es installiert haben. In jedem Fall können Sie Ihre aktuelle Version unter **Einstellungen → OhPiChamber → Über** prüfen.

## Desktop-App

Die Desktop-App prüft GitHub-Releases auf Updates. Wenn eines verfügbar ist, informiert OhPiChamber Sie, lädt es auf Wunsch herunter und installiert es beim nächsten Neustart. Sie behalten immer die Kontrolle — nichts wird ohne Ihr Zutun installiert.

## Verwandt

- [Installieren](/install/) — wie die jeweilige App überhaupt installiert wird
