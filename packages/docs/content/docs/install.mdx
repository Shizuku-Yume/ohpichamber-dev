# Install

Pick the app that fits how you work:

- a desktop app for macOS, Windows, and Linux
- a web app hosted by the CLI, which can also be installed as a PWA
- a mobile app for iOS and Android

## Desktop

Download the latest build from the [download page](https://openchamber.dev/download/) or [GitHub Releases](https://github.com/openchamber/openchamber/releases/latest), then open it. Linux builds come as `.deb`, `.rpm`, and AppImage.

## Web + PWA

Running OpenChamber requires Node.js 24.14+ for the Host Gateway, Bun 1.3.14+ on PATH for the Agent Service, and git.

```bash
curl -fsSL https://raw.githubusercontent.com/openchamber/openchamber/main/scripts/install.sh | bash
openchamber --ui-password be-creative-here
```

Open the URL the CLI prints (usually `http://localhost:3000`). Enter your UI password on the login screen to sign in. Once signed in, you will see the OpenChamber session list. To keep it handy, use your browser's "Install" option in the address bar to add it as an app.

Install the iPhone app through TestFlight or the Android app from the latest release, then pair it with your computer. [Mobile Apps](/mobile/) walks through both.

## Mobile

Install the iPhone app through TestFlight or the Android app from the latest release, then pair it with your computer. [Mobile Apps](/mobile/) walks through both.

## Nix

On NixOS, or any Linux with Nix, the flake in the OpenChamber repository builds the same apps:

```bash
nix run github:openchamber/openchamber        # web server on http://localhost:3000
nix run github:openchamber/openchamber#gui    # desktop app
```

The flake also exposes `packages.openchamber` and `packages.openchamber-desktop`, and a `nixosModules.openchamber` systemd module with `host`, `port`, `openFirewall` and `uiPasswordFile`. The password file is read through systemd's `LoadCredential`, so a root-owned 0400 secret works with the default dynamic user.
