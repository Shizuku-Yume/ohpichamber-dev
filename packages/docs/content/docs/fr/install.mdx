# Installation

Choisissez l’application qui correspond à votre façon de travailler :

- application desktop pour macOS, Windows et Linux
- application web servie par la CLI, installable sous forme de PWA
- application mobile pour iOS et Android

## Web + PWA

L'exécution du serveur OpenChamber requiert les prérequis validés : Node.js 24.14+ pour le Host Gateway, Bun 1.3.14+ sur le PATH pour l'Agent Service et git.

```bash
curl -fsSL https://raw.githubusercontent.com/openchamber/openchamber/main/scripts/install.sh | bash
openchamber --ui-password be-creative-here
```

Ouvrez l’URL affichée par la CLI (souvent `http://localhost:3000`). Entrez votre mot de passe UI sur l'écran de connexion pour vous connecter. Une fois connecté, vous verrez la liste des sessions OpenChamber. Pour la garder à portée de main, utilisez l’option « Installer » de votre navigateur dans la barre d’adresse pour l’ajouter comme application.
