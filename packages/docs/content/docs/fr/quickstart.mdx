# Démarrage rapide

## Chemin le plus rapide

1. Installez OpenChamber et vérifiez les prérequis (Node.js 24.14+ et Bun 1.3.14+ sur le PATH, voir [Installation](/install/)).
2. Lancez `openchamber --ui-password be-creative-here`.
3. Ouvrez l’URL affichée par la CLI (souvent `http://localhost:3000`) et connectez-vous avec votre mot de passe UI.
4. Pour l’utiliser depuis votre téléphone, démarrez un [tunnel](/tunnels/) et scannez le QR code.

Après vous être connecté, vous verrez la liste des sessions OpenChamber dans votre navigateur. Si elle se charge, tout est prêt.

Utilisez un mot de passe UI robuste, surtout si vous prévoyez d’ouvrir l’instance à internet.

Si la page ne se charge pas, consultez le [dépannage](/troubleshooting/).

## Quelle application utiliser ?

- utilisez **desktop** pour le travail quotidien sur macOS, Windows ou Linux
- utilisez **web** pour l’accès distant et la revue depuis votre téléphone
