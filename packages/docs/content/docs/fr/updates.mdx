# Mises à jour

La façon de mettre OhPiChamber à jour dépend de votre méthode d’installation. Dans tous les cas, vous pouvez vérifier votre version actuelle dans **Paramètres → OhPiChamber → À propos**.

## Application desktop

L’application desktop vérifie les mises à jour via les releases GitHub. Quand une mise à jour est disponible, OhPiChamber vous le signale, la télécharge lorsque vous le choisissez et l’installe au prochain redémarrage. Vous gardez toujours le contrôle — rien ne s’installe sans votre accord.
