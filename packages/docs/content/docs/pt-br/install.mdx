# Instalação

O OpenChamber pode ser executado como:

- app de desktop para macOS, Windows e Linux
- app web hospedado pela CLI, que também pode ser instalado como PWA
- app mobile para iOS e Android

## Web + PWA

Executar o servidor do OpenChamber requer o cumprimento dos pré-requisitos: Node.js 24.14+ para o Host Gateway, Bun 1.3.14+ no PATH para o Agent Service e git.

```bash
curl -fsSL https://raw.githubusercontent.com/openchamber/openchamber/main/scripts/install.sh | bash
openchamber --ui-password be-creative-here
```

Abra a URL que a CLI imprime (geralmente `http://localhost:3000`). Digite sua senha de UI na tela de login para entrar. Após o login, você verá a lista de sessões do OpenChamber. Para deixá-lo à mão, use a opção "Instalar" do seu navegador na barra de endereço para adicioná-lo como um app.

## Desktop

Baixe a build de desktop mais recente para sua plataforma na página de releases do GitHub ou na página de download do OpenChamber. Abra o app e selecione seu workspace ou conecte a um servidor remoto.
