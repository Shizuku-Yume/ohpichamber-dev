# Atualizações

Como você atualiza o OhPiChamber depende de como o instalou. Em todos os casos, você pode verificar sua versão atual em **Settings → OhPiChamber → About**.

## App de desktop

O app de desktop verifica atualizações nas releases do GitHub. Quando há uma disponível, o OhPiChamber avisa você, baixa-a quando você escolhe e a instala no próximo reinício. Você está sempre no controle — nada é instalado sem a sua autorização.
