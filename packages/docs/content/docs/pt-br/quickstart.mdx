# Início rápido

## Caminho mais rápido

1. Instale o OpenChamber e garanta que os pré-requisitos (Node.js 24.14+ e Bun 1.3.14+ no PATH) estejam atendidos (veja [Instalação](/pt-br/install/)).
2. Execute `openchamber --ui-password be-creative-here`.
3. Abra a URL que a CLI imprime (geralmente `http://localhost:3000`) e faça login com sua senha de UI.
4. Para usar pelo celular, inicie um [túnel](/pt-br/tunnels/) e escaneie o QR code.

Você deve ver a lista de sessões do OpenChamber no navegador. Se ela carregar, está tudo funcionando.

Use uma senha de UI forte, principalmente se pretende expor a instância à internet.

Se a página não carregar, confira a [Solução de problemas](/pt-br/troubleshooting/).

## Qual plataforma devo usar?

- use **desktop** para o uso diário no macOS, Windows ou Linux
- use **web** para acesso remoto e revisão pelo celular
