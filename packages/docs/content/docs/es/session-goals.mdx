# Objetivos de sesión

Los objetivos usan el modo Goal de OMP en el worker del Agent Service. OMP inicia las continuaciones y el agente declara cuándo termina; OpenChamber no ejecuta un supervisor ni un auditor independiente.

Un objetivo reúne un prompt y una condición de finalización. OMP continúa hasta que el agente declara que se completó, se alcanza el presupuesto de tokens, no hay progreso o detienes el objetivo.

## Iniciar un objetivo

1. Pulsa el botón de diana en el compositor. Se ilumina — el modo objetivo está armado.
2. Escribe tu prompt y envíalo. Ese mensaje se convierte en el objetivo.

Funciona igual en una sesión existente y en un borrador de sesión nueva: arma la diana, escribe el primer mensaje, envía — la nueva sesión arranca con el objetivo ya activo.

### Más formas de iniciar un objetivo

- **Desde una respuesta del agente**: en el diálogo para iniciar una sesión desde la respuesta, marca **Ejecutar como objetivo**.
- **Desde un plan**: al implementar un plan guardado en una sesión o worktree nuevos, marca **Ejecutar como objetivo**. El contenido del plan es el objetivo de OMP.
- **Según un horario**: marca **Ejecutar como objetivo** en una [tarea programada](/scheduled-tasks/).
- **Desde la CLI**: usa `openchamber session create --prompt <p> --goal`; `session send` y `session fork` también aceptan `--goal`.

## Escribe un objetivo autocontenido

El auditor de progreso solo ve tu objetivo y la última respuesta del agente — no el historial del chat. Redacta el mensaje-objetivo de forma que alguien sin el contexto de la conversación entienda cómo es el estado final.

- Bien: "Añade tests para el módulo de exportación y haz que toda la suite pase."
- No tan bien: "Arréglalo" o "Continúa con esa idea."

Para pequeños ajustes contextuales no necesitas un objetivo — envía un mensaje normal.

## Cómo funciona

OMP inicia cada continuación dentro de la sesión. El agente declara que terminó con la herramienta de objetivos; OMP también se detiene al alcanzar el presupuesto opcional, cuando una continuación no logra avanzar, o cuando pausas, eliminas o abortas el objetivo.

### Detener y reanudar

- El **botón de detener** aborta el turno en curso; OMP pausa el objetivo.
- **Pausar** en el panel del objetivo también detiene el turno en curso.
- Mientras está pausado, chatea con normalidad.
- **Reanudar** vuelve a activar las continuaciones de OMP.

## Observar y gestionar

- La franja sobre el compositor muestra el objetivo, el estado y el uso de tokens, con controles para pausar o reanudar.
- El botón de diana y el icono de la barra lateral muestran el estado de Goal de OMP.
- El diálogo del objetivo permite cambiar el objetivo o el presupuesto, o eliminar el objetivo.

## Notificaciones

Mientras el modo Goal está activo, no se envía una notificación de "agente listo" después de cada turno. OMP envía una notificación cuando el objetivo se completa o alcanza su presupuesto. Las solicitudes de permisos, las preguntas y las notificaciones de error siguen funcionando con normalidad.

## Presupuesto de tokens

En **Ajustes → Chat → Objetivo** puedes definir un presupuesto predeterminado para los nuevos objetivos. Al alcanzarlo, OMP detiene el objetivo; puedes actualizar el presupuesto y reanudarlo.

## Ten en cuenta

- OMP es el único propietario del modo y las continuaciones del objetivo; el Host no mantiene un bucle separado.
- Los metadatos antiguos del supervisor de Host no se convierten en un objetivo de OMP.
- Solo hay un objetivo por sesión.
