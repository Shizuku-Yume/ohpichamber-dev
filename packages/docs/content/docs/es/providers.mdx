# Proveedores, modelos y agentes

Antes de que OpenChamber pueda hacer algo, necesita al menos un proveedor de IA conectado. Esta página cubre cómo conectar un proveedor, elegir un modelo y ajustar los agentes.

## Conecta un proveedor

1. Abre **Settings → Providers**.
2. Abre el menú **Add provider** y elige un proveedor que aún no esté conectado.
3. Inicia sesión de una de estas dos formas, según el proveedor:
   - **Clave de API** — pega tu clave y guarda.
   - **Inicio de sesión OAuth** — abre el enlace de autorización en tu navegador para iniciar sesión. Si se solicita, pega el código de autorización en OpenChamber y completa la conexión.

### Proveedores personalizados y otros

Para pasarelas, LLM locales, Ollama, LiteLLM y API similares compatibles con OpenAI:

1. Elige **Other / Custom** en la lista de proveedores.
2. Introduce un ID de proveedor, nombre visible, URL base (`http://` o `https://`), una clave de API opcional y al menos un ID y nombre de modelo.
3. Indica la ventana de contexto y el límite máximo de tokens de salida del modelo. Los metadatos avanzados (como opciones de razonamiento, variantes y modalidades) se pueden configurar como JSON en los detalles del modelo.
4. Añade encabezados de solicitud opcionales.
5. Guarda — OpenChamber registra el proveedor y los modelos mediante el Agent Service, almacenando las claves de API como credenciales de solo escritura.
6. Para modificar un proveedor personalizado existente, ábrelo y elige **Edit**.

La clave de API es opcional. Los endpoints locales sin clave (como Ollama, LiteLLM o llama.cpp) y los servicios autenticados mediante encabezados personalizados se pueden conectar sin clave de API.

Cuando un proveedor aparece como conectado, sus modelos quedan disponibles en el chat.

Para desconectar, abre el proveedor y elige eliminar su inicio de sesión.

## Elige un modelo

Eliges el modelo en el lugar donde trabajas:

- en el chat, usa el selector de modelo de la barra de mensajes para fijar el proveedor y el modelo de esa sesión
- por agente, define un modelo predeterminado (más abajo)

## Configura agentes

Un agente es una configuración con nombre: un modelo, una personalidad y lo que se le permite hacer.

1. Abre **Settings → Agents**.
2. Elige un agente o crea uno nuevo.
3. Edita cualquiera de estos campos:
   - **description** — para qué sirve el agente
   - **model** — su modelo predeterminado
   - **temperature** — qué tan creativas son sus respuestas
   - **prompt** — instrucciones permanentes que siempre sigue
   - **tool rules** — qué herramientas puede usar

## Dónde se guardan tus inicios de sesión

Las credenciales y los inicios de sesión de los proveedores se guardan en el almacén de credenciales del Agent Service en el servidor, manteniendo las claves protegidas y aisladas. Puedes conectar varias cuentas para un mismo proveedor y seleccionar en la lista de cuentas del proveedor cuál se usa como predeterminada.
