# Inicio rápido

## La vía más rápida

1. Instala OpenChamber y asegúrate de cumplir los requisitos previos (Node.js 24.14+ y Bun 1.3.14+ en el PATH, consulta [Instalación](/es/install/)).
2. Ejecuta `openchamber --ui-password be-creative-here`.
3. Abre la URL que imprime la CLI (normalmente `http://localhost:3000`) e inicia sesión con tu contraseña de UI.
4. Para usarlo desde tu teléfono, inicia un [túnel](/es/tunnels/) y escanea el código QR.

Deberías ver la lista de sesiones de OpenChamber en tu navegador. Si carga, ya está todo en marcha.

Usa una contraseña de UI fuerte, sobre todo si piensas exponer la instancia a internet.

Si la página no carga, consulta [Resolución de problemas](/es/troubleshooting/).

## ¿Qué app debería usar?

- usa **escritorio** para el día a día en macOS, Windows o Linux
- usa **web** para acceso remoto y revisión desde el teléfono
