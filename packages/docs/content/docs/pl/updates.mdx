# Aktualizacje

Sposób aktualizacji OhPiChamber zależy od tego, jak go zainstalowałeś. W każdym przypadku możesz sprawdzić swoją bieżącą wersję w **Settings → OhPiChamber → About**.

## Aplikacja na komputerze

Aplikacja na komputerze sprawdza aktualizacje względem wydań na GitHub. Gdy jedna jest dostępna, OhPiChamber Cię informuje, pobiera ją, gdy zdecydujesz, i instaluje przy następnym restarcie. Zawsze masz kontrolę — nic nie instaluje się bez Twojej zgody.
