# Aktualizacje

Sposób aktualizacji OhPiChamber zależy od tego, jak go zainstalowałeś. W każdym przypadku możesz sprawdzić swoją bieżącą wersję w **Settings → OhPiChamber → About**.

## Wersja webowa / CLI

Jeśli zainstalowałeś CLI, zaktualizuj je z poziomu **About** za pomocą przycisków sprawdzania i aktualizacji albo z terminala:

```bash
openchamber update
```

OpenChamber wykrywa, jak został zainstalowany (npm, pnpm, yarn lub bun), i uruchamia właściwą aktualizację za Ciebie.

## Serwer OpenCode

OpenChamber i OpenCode aktualizują się osobno. Gdy dostępna jest nowa wersja OpenCode, OpenChamber proponuje jej aktualizację i restartuje serwer po jej zakończeniu. Zobacz [OpenCode Server](/pl/opencode-server/), aby dowiedzieć się, jak ten serwer jest zarządzany.

## Aplikacja na Androida

Gdy wychodzi nowa wersja aplikacji na Androida, powiadomienie proponuje jej pobranie. Zamknięcie powiadomienia pomija tę wersję tylko w powiadomieniu: **Settings → OpenChamber → About** pokazuje przycisk **Download app** obok wersji aplikacji, dopóki jej nie zainstalujesz, a przycisk sprawdzania sprawdza tam także aplikację. Pozostałe przyciski aktualizacji w About aktualizują serwer, z którym aplikacja jest połączona, a nie samą aplikację.

Aplikacja na iOS aktualizuje się przez App Store.

## Serwer OpenCode

OpenChamber i OpenCode aktualizują się osobno. Gdy dostępna jest nowa wersja OpenCode, OpenChamber proponuje jej aktualizację i restartuje serwer po jej zakończeniu. Zobacz [OpenCode Server](/pl/opencode-server/), aby dowiedzieć się, jak ten serwer jest zarządzany.
