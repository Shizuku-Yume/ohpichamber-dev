# Instalacja

Wybierz aplikację, która pasuje do twojego sposobu pracy:

- aplikacja desktopowa dla macOS, Windows i Linux
- aplikacja webowa hostowana przez CLI, którą można zainstalować jako PWA
- aplikacja mobilna dla iOS i Android

## Przeglądarka + PWA

Uruchomienie serwera OpenChamber wymaga spełnienia wymagań wstępnych: Node.js 24.14+ dla Host Gateway, Bun 1.3.14+ w zmiennej PATH dla Agent Service oraz git.

```bash
curl -fsSL https://raw.githubusercontent.com/openchamber/openchamber/main/scripts/install.sh | bash
openchamber --ui-password be-creative-here
```

Otwórz adres URL wypisany przez CLI (zwykle `http://localhost:3000`). Wprowadź hasło UI na ekranie logowania, aby się zalogować. Po zalogowaniu pojawi się lista sesji OpenChamber. Aby mieć ją zawsze pod ręką, użyj opcji „Zainstaluj” w pasku adresu przeglądarki, aby dodać ją jako aplikację.
