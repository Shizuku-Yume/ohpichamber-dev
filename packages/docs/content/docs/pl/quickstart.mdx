# Szybki start

## Najszybsza droga

1. Zainstaluj OpenChamber i upewnij się, że spełnione są wymagania wstępne (Node.js 24.14+ i Bun 1.3.14+ w PATH, zobacz [Instalacja](/pl/install/)).
2. Uruchom `openchamber --ui-password be-creative-here`.
3. Otwórz adres URL wypisany przez CLI (zwykle `http://localhost:3000`) i zaloguj się hasłem UI.
4. Aby korzystać z telefonu, uruchom [tunel](/pl/tunnels/) i zeskanuj kod QR.

Po zalogowaniu w przeglądarce pojawi się lista sesji OpenChamber. Jeśli się załadowała, wszystko działa.

Używaj silnego hasła UI, zwłaszcza jeśli planujesz udostępnić instancję w internecie.

Jeśli strona się nie ładuje, zajrzyj do [Rozwiązywania problemów](/pl/troubleshooting/).

## Której platformy użyć?

- użyj **komputera** do codziennej pracy na macOS, Windows lub Linux
- użyj **przeglądarki** do zdalnego dostępu i przeglądania na telefonie
